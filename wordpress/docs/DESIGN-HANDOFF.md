# AI 入稿データ → コードの対応

支給された Illustrator データをこのテーマに落とし込むときの手順です。
**色・級数・余白の調整は `assets/css/tokens.css` だけで完結します。**
ページごとの CSS はトークンしか参照していないため、個別ファイルを触る必要は
原則ありません。

## 1. まず AI から拾う値

| AI 側 | コード側（tokens.css） | 備考 |
| --- | --- | --- |
| スウォッチ（企業色） | `--c-primary` / `--c-primary-dark` / `--c-primary-light` | 濃淡は AI に無ければ primary から生成 |
| スウォッチ（アクセント） | `--c-accent` | 必須ラベル・強調に使用 |
| 本文の文字色 | `--c-text` / `--c-text-weak` | 弱い方は注記・補足文 |
| 背景のグレー | `--c-bg-subtle` | セクション交互の背景 |
| 罫線の色 | `--c-border` / `--c-border-strong` | 入力欄の枠は strong |
| 文字設定の級数 | `--fs-xs` 〜 `--fs-4xl` | **pt の数値をそのまま 1/10 して rem** で入れる |
| 行送り | `--lh-base` / `--lh-heading` | 和文本文は 1.9 前後になることが多い |
| トラッキング | `--ls-base` / `--ls-wide` | AI の「文字ツメ」1000 = 1em |
| アートボードのコンテンツ幅 | `--w-container` | 左右マージンを除いた実寸 |
| セクション間の余白 | `--section-py` | PC と SP で別値 |
| 角丸 | `--radius` / `--radius-lg` | |

### 級数の入れ方

`html { font-size: 62.5%; }` を敷いてあるので **1rem = 10px** です。
AI 上で 15pt の本文なら `--fs-base: 1.5rem;` と書けます。換算表は不要です。

## 2. 書体について

和文は Web フォントを使わず、OS 標準のゴシックを指定しています（`--ff-base`）。

支給デザインが游ゴシックやヒラギノ以外の**有償フォント**で組まれている場合は、
以下のいずれかを確認してください。表示確認の前に決めておかないと、
全ページで行数がずれます。

1. Web フォントのライセンスをクライアントが保有しているか
2. Adobe Fonts / Google Fonts の類似書体に寄せるか
3. 見出しのみ画像化するか（文字数が固定の箇所のみ推奨）

現状は 2 を前提に、`BIZ UDPGothic` を含むフォールバックを組んであります。

## 3. 画像の書き出し

`assets/img/` に配置します。テンプレートが参照しているファイル名:

| ファイル名 | 使用箇所 | 推奨書き出しサイズ |
| --- | --- | --- |
| `hero.jpg` | トップ キービジュアル | 1600 × 1000 |
| `business-01.jpg` 〜 `03.jpg` | トップ／事業ページ | 960 × 640 |
| `president.jpg` | 会社概要 ごあいさつ | 720 × 900 |

- 写真は JPEG（品質 80 前後）、図版・ロゴは SVG
- Retina 対応が必要な箇所は 2倍で書き出して CSS 側で縮小
- `alt` はデザイン上の装飾画像には空（`alt=""`）を入れてあります。
  内容を持つ画像に差し替える場合は `alt` も記述してください

## 4. ピクセル調整の進め方

1. `docker compose up -d` でローカルを立ち上げる
2. AI を PNG で書き出し（PC 幅 / SP 幅の2種）、ブラウザに重ねて比較
   （Chrome 拡張の PerfectPixel など。実機確認は別途）
3. ズレたら **まず `tokens.css`** を疑う。全体的にズレている場合はほぼトークン側
4. 1か所だけのズレは `pages.css` の該当セクションで調整

`body` にページ判別用のクラス（`p-home` / `p-company` …）が付くので、
特定ページだけの微調整もセレクタを足すだけで済みます。

## 5. ブレークポイント

現在 767px / 1024px の2点で切っています。AI の SP アートボードが
別の幅（375px 基準など）の場合は `tokens.css` 末尾のメディアクエリと
`components.css` / `pages.css` の `@media` を合わせて変更してください。

## 6. 確認が必要な事項

デザイン反映の前に、以下を確定させてください（未確定のままだと手戻りが出ます）。

- [ ] 使用書体とライセンス（上記 2）
- [ ] ロゴデータ（SVG 推奨。管理画面の「カスタムロゴ」からも設定可）
- [ ] 正式社名・住所・電話番号・FAX（`inc/setup.php` の `seizo_company()`）
- [ ] 問い合わせ通知の受信メールアドレス
- [ ] お問い合わせ種別の選択肢（現在6種を仮置き）
- [ ] 個人情報保護方針の本文
- [ ] 製品一覧のリンク先 URL（現行サイトの各カテゴリ）
- [ ] 沿革・設備一覧・募集要項の原稿
- [ ] favicon / OGP 画像
