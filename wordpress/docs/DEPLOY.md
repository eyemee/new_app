# 本番サーバーへの反映

クライアントの既存サーバーに、このテーマを設置する手順です。
**アップロードするのは `wp-content/themes/seizo/` の一式のみ**です。
`docker-compose.yml` と `dev/` は開発用のため持っていきません。

## 事前確認（クライアント／貴社にて）

- [ ] WordPress のバージョン（6.4 以上）
- [ ] PHP のバージョン（8.0 以上）
- [ ] FTP / SFTP または SSH の接続情報
- [ ] 現行サイトとの関係（同一ドメインか、サブディレクトリか）
- [ ] サーバーから外部への HTTPS 通信が許可されているか
      （郵便番号検索で使用。不可の場合は下記「外部通信が使えない場合」へ）
- [ ] メール送信の方式（サーバーの `mail()` か、SMTP か）

## 手順

### 1. アップロード

```
wp-content/themes/seizo/   ←  このディレクトリごと設置
```

### 2. wp-config.php に追記

```php
// お問い合わせの通知先。未定義の場合は管理者メールアドレスが使われます。
define( 'SEIZO_CONTACT_TO', 'info@example.co.jp' );

// 管理画面からのファイル編集を禁止（誤操作・改ざん対策）
define( 'DISALLOW_FILE_EDIT', true );
```

### 3. テーマを有効化

管理画面 → 外観 → テーマ → **Seizo Corporate** を有効化。

有効化した時点で以下が自動生成されます（既存の同名ページがある場合は作りません）。

- 固定ページ7点（`home` / `company` / `business` / `quality` / `recruit` / `contact` / `privacy`）
- グローバルナビ・フッターナビ
- お知らせカテゴリー4種
- トップページの設定（`home` を固定フロントページに指定）

### 4. パーマリンク設定

設定 → パーマリンク → **投稿名** を選んで保存。
お知らせの URL（`/news/...`）に必要です。保存するだけで反映されます。

### 5. 動作確認

- [ ] 7ページすべてが表示される
- [ ] SP 幅でドロワーメニューが開閉する
- [ ] お知らせを1件投稿 → トップと一覧に出る
- [ ] お問い合わせ: 入力 → 確認 → 完了 まで通る
- [ ] 通知メールと自動返信メールが届く（迷惑メール判定も確認）
- [ ] 郵便番号を入力すると住所が補完される
- [ ] 製品一覧のリンクが現行サイトに飛ぶ

## メールが届かない場合

サーバーの `mail()` 関数が使えない、または送信元ドメインの SPF が理由で
弾かれることがあります。その場合は SMTP 送信に切り替えてください。
テーマ側は `wp_mail()` を使っているため、SMTP プラグインを入れるか、
`phpmailer_init` フックで設定すれば、テーマの変更なしで切り替わります。

`dev/mu-plugins/00-dev-mail.php` が実装例です（開発環境用）。

## 外部通信が使えない場合（郵便番号検索）

既定では郵便番号から住所を引くのに外部 API を使います。サーバーが
外向き通信を許可していない場合は、`seizo_zipcode_provider` フィルタで
ローカルの住所テーブルを返すように差し替えてください。
フロントエンド側の変更は不要です。

```php
add_filter( 'seizo_zipcode_provider', function ( $address, $zipcode ) {
	// 日本郵便の KEN_ALL から作成したテーブルを引く
	return array(
		'prefecture' => '愛知県',
		'city'       => '名古屋市中区',
		'town'       => '栄',
		'full'       => '愛知県名古屋市中区栄',
	);
}, 10, 2 );
```

## 更新時

テーマファイルを差し替えるだけです。DB の変更は不要です。
CSS / JS はファイル更新時刻をバージョンに使っているため、
差し替えれば閲覧者のキャッシュも自動で切り替わります。

サーバー側にキャッシュ機構（LiteSpeed Cache など）がある場合は、
差し替え後にキャッシュの削除が必要です。
